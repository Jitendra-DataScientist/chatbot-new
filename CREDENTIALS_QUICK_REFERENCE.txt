🚀 QUICK START (5 MINUTES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Create Google Sheet
  └─ Go to https://sheets.google.com
  └─ Create new sheet named "Tableau Credentials Store"
  └─ Rename first sheet to "Credentials"
  └─ Add headers: username | password | site_content_url | tableau_server_url | api_version
  └─ Add your data starting from Row 2

STEP 2: Deploy Apps Script
  └─ In your sheet: Extensions > Apps Script
  └─ Copy code from: google_apps_script_for_credentials.js
  └─ Deploy > New deployment > Web app
  └─ Execute as: Me | Who has access: Anyone
  └─ Copy the Web App URL

STEP 3: Update Configuration
  └─ Open: google_sheets_config.json
  └─ Find: "tableau_credentials" section
  └─ Set: "enabled": true
  └─ Set: "apps_script_url": "YOUR_WEB_APP_URL"

STEP 4: Test
  └─ Run: python test_credentials_service.py

OPTION 1: Smart Fallback (Recommended)
────────────────────────────────────────────────────────────────────────
from services.tableau_credentials_service import load_tableau_config

# Tries Google Sheets first, falls back to pass_config.json
config = load_tableau_config(username="cca49542@gmail.com")

# Use as before
server_url = config['tableau_server_url']
password = config['password']
────────────────────────────────────────────────────────────────────────

OPTION 2: Direct Lookup (Google Sheets only)
────────────────────────────────────────────────────────────────────────
from services.tableau_credentials_service import get_tableau_credentials

success, credentials, error = get_tableau_credentials("cca49542@gmail.com")

if success:
    username = credentials['username']
    password = credentials['password']
    site_url = credentials['site_content_url']
else:
    print(f"Error: {error}")
────────────────────────────────────────────────────────────────────────

OPTION 3: Replace Existing Code
────────────────────────────────────────────────────────────────────────
BEFORE:
  import json
  with open('pass_config.json', 'r') as f:
      config = json.load(f)

AFTER:
  from services.tableau_credentials_service import load_tableau_config
  config = load_tableau_config(username="cca49542@gmail.com")

🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"Credentials service is disabled"
  → Set "enabled": true in google_sheets_config.json

"Apps Script URL not configured"
  → Add your Web App URL to "apps_script_url" in config

"Credentials not found for username"
  → Verify username exists in Column A
  → Check sheet name is "Credentials"
  → Ensure Row 1 is headers, data starts from Row 2

"Connection error"
  → Check internet connection
  → Verify Apps Script URL is correct
  → Ensure Apps Script is deployed (not just saved)

"Request timeout"
  → Increase "timeout_seconds" in config
  → Check Google Apps Script status
