┌─────────────────────────────────────────────────────────────────────────────┐
│                           SECURITY ARCHITECTURE                             │
└─────────────────────────────────────────────────────────────────────────────┘

   SECURITY LAYERS:

   1. Google Account Authentication
      └─ Apps Script runs under your Google account
      └─ Requires Google authentication to access

   2. Google Sheet Permissions
      └─ Share only with authorized users
      └─ Restrict to "Specific people" or "Anyone with link"

   3. Apps Script Deployment Permissions
      └─ Deploy as "Anyone" or "Anyone with link"
      └─ Apps Script URL is secret (acts as API key)

   4. In-Memory Caching Only
      └─ No persistent credential storage
      └─ Cache clears on app restart

   5. Git Ignored Files
      └─ pass_config.json → Ignored
      └─ google_apps_script_for_credentials.js → Ignored
      └─ Prevents accidental credential commits

   6. HTTPS Transport
      └─ All communication over HTTPS
      └─ Encrypted in transit


┌─────────────────────────────────────────────────────────────────────────────┐
│                         ERROR HANDLING & RECOVERY                           │
└─────────────────────────────────────────────────────────────────────────────┘

   SCENARIO 1: Google Sheets Unavailable
   ────────────────────────────────────────────────────────────────────────
   Google Sheets Down → Retry (2x) → Fallback to pass_config.json → Success
   
   SCENARIO 2: Network Timeout
   ────────────────────────────────────────────────────────────────────────
   Request Timeout → Retry with exponential backoff → Fallback → Success
   
   SCENARIO 3: Credential Not Found
   ────────────────────────────────────────────────────────────────────────
   Username Not in Sheet → Return error → Fallback to pass_config.json
   
   SCENARIO 4: Service Disabled
   ────────────────────────────────────────────────────────────────────────
   enabled: false → Skip Google Sheets → Use pass_config.json directly
