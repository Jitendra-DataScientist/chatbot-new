ARCHITECTURE CLARIFICATION (Your Question About LUID)
================================================================================

Question: "Shall we use LUID instead of dash name everywhere?"

Answer: You're ALREADY using LUID correctly!

Current system (CORRECT):
  - User LUID: Identifies the user (from Tableau getSessionInfo API)
  - Workbook Name: Identifies the workbook (for file paths)
  - Session UUID: Identifies the browser tab/session

Session key structure:
  {user_luid}:{workbook_name}:{session_uuid}
  
Example:
  "19993dac-d11f-4d8d-84e2-101d4d88e78a:FRO Dashboard_new_updated:fd8f179d..."
  
Why this is correct:
  ✅ User isolation via LUID
  ✅ Workbook isolation via workbook_name
  ✅ Session isolation via session UUID
  ✅ Workbook name needed for file paths: tableau_exports/{workbook_name}/
  
No changes needed. The architecture is correct.
